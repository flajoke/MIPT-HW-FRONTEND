# Homework 5 — Chat UI

Готовый проект на React + TypeScript + Vite.

## Что реализовано

- контролируемая форма с `textarea`
- отправка по кнопке
- отправка по `Enter`
- перенос строки по `Shift+Enter`
- блокировка пустой отправки
- кнопка `Стоп` во время загрузки
- кнопка `Копировать` у сообщений ассистента
- визуальная обратная связь после копирования
- светлая и тёмная темы через CSS-переменные
- адаптивная вёрстка от мобильных до десктопа

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
